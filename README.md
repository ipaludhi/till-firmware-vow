One original one-line wedding vow, spoken by a robot at its own wedding, for make.fun's "Till Firmware Do Us Part" bounty: built to last five years, intending to love for six. (63 characters, 63 bytes.)

## Run it

```sh
node main.ts
```

It writes the vow to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline. Node 22, stdlib only, no network. Three runs are byte-identical.
